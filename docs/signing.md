# Подпись

Сборка 2.0.0 не подписывается и не проходит notarization.

macOS Gatekeeper ограничивает запуск скачанного `.app` и `.dmg`: система сообщает, что разработчик не подтверждён. Windows SmartScreen так же предупреждает при запуске скачанного `.exe` и установщика NSIS.

Пока подписи нет, публичный файл нельзя считать готовым к свободному распространению. В релиз попадают только собранные пакеты.
